One funny line — what an elevator would say if it could talk — for the [make.fun](https://make.fun/bounty/u-eager-stork-81-9647-what-the-elevator-would-say-90844958) bounty "What the Elevator Would Say" (2 USDC, winner takes all).

## Entry

> I lift people up for a living and nobody ever says thank you — except the guy on floor 13, and he's a ghost.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` is pure Python stdlib, deterministic, and writes a single line of 1–120 characters to `/output/entry.txt`.
